# Security Policy

This document details the security policies, vulnerability disclosure procedures, and threat models for the project.

## Threat Models
- **STRIDE++**: Extension of STRIDE for LLM-specific vulnerabilities, such as:
  - Agent Identity Hijacking
  - Prompt Injection
  - Cross-Session Token Leakage
  - Semantic Cache Collision

## Vulnerability Disclosure
- Responsible disclosure practices.
- Security contact information.

## Best Practices
- Dependency scanning.
- Static Application Security Testing (SAST).
- Strict separation between formal validation (L0-L4) and physical implementations.
