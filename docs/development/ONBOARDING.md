# Onboarding

Welcome to the project! This guide is designed to help new team members get up and running quickly.

## First Steps
1. Familiarize yourself with the `README.md`.
2. Read the architectural overview in `docs/architecture/ARCHITECTURE.md`.
3. Check the contribution guidelines in `docs/development/CONTRIBUTING.md`.

## Setup Environment
- Ensure Rust and Cargo are installed.
- Ensure Lean 4 and Lake are installed.
- Configure pre-commit hooks and local environment variables.

## Getting Help
- Reach out to the team via the official communication channels.
- Check the `MEMORY.md` for historical context and project knowledge.
